# Ruang Magang

**Live demo:** https://ruang-magang.vercel.app

Frontend Next.js untuk demonstrasi dashboard magang mahasiswa. Data bersifat lokal dan fiktif; tidak ada autentikasi, penyimpanan data, atau VPS.

## Jalankan

```sh
npm install
npm run dev
```

`GET /api/magang` menyediakan data demo yang sama untuk kebutuhan integrasi frontend. Endpoint ini berjalan sebagai route handler Next.js dan dapat diterapkan ke Vercel tanpa mengelola VPS.
